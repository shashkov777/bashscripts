# Bash Scripts

Коллекция bash-скриптов для администрирования Linux: работа с пользователями, проверка прав, изменение учётных записей и групп.

## script1 - проверка прав пользователя

Запрашивает имя пользователя и проверяет, существует ли он и является ли администратором (UID 0).

## script2 — проверка использования sudo

Запрашивает имя пользователя и проверяет по истории bash (.bash_history), использовал ли он sudo.

## script3 — изменение параметров пользователя

Запрашивает имя пользователя и позволяет изменить:

- uid — идентификатор пользователя (с проверкой, что он не занят)
- homedir — домашнюю директорию (с проверкой, что она существует)
- group — основную или дополнительную группу.

## script4 — создание пользователей из файла

Читает список имён из файла file_user (по одному на строку) и создаёт пользователей через useradd.
